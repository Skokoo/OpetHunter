# Security Policy for Opet

Security updates and patches are exclusively provided for the latest release branch of the Opet project.

## 2. Reporting a Vulnerability
If you discover a security vulnerability or a critical memory leak within this framework, please refrain from opening a public issue. 

Instead, report the issue directly via the public email address listed on my GitHub profile. 

Every report will be reviewed as promptly as possible based on current availability. Thank you for helping keep the Opet project secure.

# Code of Conduct

## 1. My Pledge
I want to keep this project a chill, respectful, and zero-drama space for anyone who genuinely loves low-level binary engineering and talking directly to the machine. 

## 2. Expected Behavior
* **Be Cool:** Share knowledge about ARM64/x86_64, give constructive code feedback, and respect other engineering viewpoints.
* **Dont be a talkative bad guy:** Trolling, personal insults, political attacks, or leaking anyone's private details will get you banned from this repository instantly.
* **Keep It Tech-Focused:** This is a pocket decompiler project, not a social media playground.

## 3. Enforcement
If someone acts toxic or breaches these rules inside the issue tracker or discussions, I will simply block and ban them without warning.
